What does rust do to your mood?

Rust occupies a unique psychological space. It's warm like orange but more serious. Earthy like brown but more energetic. This combination creates grounding effects that connect you to the physical world while maintaining warmth and energy.

Psychological Quality How Rust Expresses It
Grounding Connects to earth, clay, natural materials

Unlike cooler colors that encourage mental expansion, rust pulls you back to the physical. It's excellent for projects that need to feel tangible, honest, and connected to the natural world.

Why Rust Feels "Authentic"

Rust is the color of things that have lived—aged metal, fallen leaves, weathered wood. Our brains associate it with natural processes and honest wear. This makes rust incredibly effective for brands and designs that want to communicate authenticity and heritage.

What is the hex code for rust?

The hex code for rust is #B7410E. Here are all the technical color values:

  • Hex: #B7410E
  • RGB: 183, 65, 14
  • HSL: 18°, 86%, 39%
  • CMYK: 0%, 64%, 92%, 28%

The high saturation (86%) gives this rust its vibrancy, while the moderate lightness (39%) keeps it from being overwhelming. The hue at 18° places it firmly in the red-orange range—warm and earthy without tipping into pure orange or brown.

How is rust different from brown and orange?

Rust sits in a family of warm, earthy colors but has distinct characteristics. Here's how it compares:

Rust vs. Brown: Brown is more neutral and subdued. Rust has more red and orange energy—it's brown's more vibrant cousin. Use brown for quiet sophistication, rust for warm intensity.

Rust vs. Orange: Orange is brighter and more playful. Rust is orange that's been grounded—more serious, more natural. Choose rust when orange feels too energetic.

Rust vs. Maroon: Maroon leans toward purple-red; rust leans toward orange-red. Maroon feels regal and formal; rust feels earthy and authentic.

Rust vs. Copper: Copper has metallic associations and slightly more pink. Rust is earthier, more like oxidized iron than polished metal.

Rust vs. Burgundy: Burgundy is deeper and more wine-like. Rust is warmer and more orange. Burgundy for elegance, rust for warmth.
